# 📚 Estruturas de Dados - Ciência da Computação (FURB)

Este repositório armazena as atividades, exercícios e projetos desenvolvidos na disciplina de Estruturas de Dados do curso de Ciência da Computação da Universidade Regional de Blumenau (FURB). 

## 🎯 Objetivos

- **Objetivo da Disciplina:** Desenvolver e aplicar os conceitos de abstração de dados, estruturas de dados clássicas, suas características funcionais, formas de representação e operações associadas.
- **Objetivo do Curso:** Formar um profissional com conhecimento científico e base sólida em computação, atendendo de forma proativa e ética às demandas da comunidade regional.

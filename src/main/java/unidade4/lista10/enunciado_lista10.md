# Lista 10 - Algoritmos de Ordenação

**Objetivo:** Implementar algoritmos clássicos de ordenação aplicados a arrays de tipos genéricos.

**Principais Operações:**
*   Uso da interface `Comparable<T>` para permitir a comparação (`compareTo()`) genérica entre objetos.
*   **Bolha (Bubble Sort) e Bolha Otimizada:** Algoritmos iterativos simples de troca de vizinhos.
*   **QuickSort:** Abordagem de divisão e conquista (particionamento com pivô).
*   **MergeSort:** Abordagem de divisão e intercalação (merge) para ordenação de sub-vetores.

# Lista 01 - Lista Estática para Inteiros

**Objetivo:** Implementar uma Lista Linear Estática utilizando um vetor primitivo de inteiros (`int[]`).

**Principais Operações:**
*   Inserção de dados com redimensionamento dinâmico (aumento automático do vetor quando cheio).
*   Busca de elementos e exclusão com deslocamento de índices.
*   Tratamento de exceção (`IndexOutOfBoundsException`) ao acessar posições inválidas.

# Lista 04 - Lista Duplamente Encadeada

**Objetivo:** Implementar uma Lista Duplamente Encadeada genérica (`<T>`), onde cada nó conhece seu sucessor (`proximo`) e seu antecessor (`anterior`).

**Principais Operações:**
*   Inserção, busca e remoção ajustando múltiplos ponteiros para manter a consistência bidirecional.
*   Navegação e exibição dos elementos em ordem inversa (do último para o primeiro).
*   Liberação completa da memória desfazendo todos os encadeamentos (`null`).

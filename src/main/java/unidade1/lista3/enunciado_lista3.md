# Lista 03 - Lista Simplesmente Encadeada

**Objetivo:** Implementar uma Lista Simplesmente Encadeada genérica (`<T>`), utilizando alocação dinâmica de memória através de nós (`NoLista`).

**Principais Operações:**
*   Encadeamento de nós contendo a referência para o `proximo`.
*   Inserção de elementos no início da estrutura.
*   Busca e remoção de nós desconectando os ponteiros.
*   Obtenção do comprimento e de um nó específico baseado em um índice numérico simulado.

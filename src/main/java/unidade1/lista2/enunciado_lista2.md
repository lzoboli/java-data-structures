# Lista 02 - Lista Estática Genérica

**Objetivo:** Evoluir a implementação da Lista Estática da Lista 01 para suportar Tipos Genéricos (`<T>`), permitindo armazenar qualquer tipo de objeto (ex: `String`, `Aluno`, etc.).

**Principais Operações:**
*   Todas as operações da Lista 01 adaptadas para *Generics*.
*   **Inversão:** Novo método `inverter()` que inverte a ordem dos dados no próprio vetor, sem criar novos arrays ou usar coleções da API do Java.

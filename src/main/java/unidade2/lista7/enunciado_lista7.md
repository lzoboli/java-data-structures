# Lista 07 - Árvores Binárias

**Objetivo:** Implementar os fundamentos de uma Árvore Binária genérica (`<T>`), onde cada nó possui no máximo dois filhos (esquerda e direita).

**Principais Operações:**
*   Construção manual das ligações hierárquicas entre os nós.
*   Busca (`pertence`) utilizando algoritmos recursivos.
*   Contagem total do número de nós da estrutura (recursivo).
*   Representação textual da árvore utilizando o percurso em pré-ordem.

# Lista 08 - Árvores N-árias

**Objetivo:** Implementar uma Árvore Genérica (N-ária), onde cada nó pode possuir um número variável e ilimitado de filhos.

**Principais Operações:**
*   Estruturação dos nós utilizando referências para o `primeiro` filho e para o `proximo` irmão.
*   Inserção de sub-árvores em um nó específico.
*   Algoritmos recursivos adaptados para buscar elementos (`pertence`) e contar a quantidade total de nós navegando pela lista de irmãos.
